# Personal landing page

Static landing page and selected-work index for Nattadet "Spite" Chinthanathatset.
No build step, no dependencies — plain HTML, CSS and JavaScript.

## Structure

```
index.html          Markup and copy — projects are plain <li> rows, edit here
css/styles.css      Tokens, aurora background, layout
js/main.js          Hover-to-play video previews (desktop only)
assets/video/       Project clips, 10 files, ~10.5 MB
assets/thumbs/      Poster frames cut from those clips, ~320 KB
.nojekyll           Stops GitHub Pages running content through Jekyll
```

## Editing

- **Add or reorder a project** — copy an `<li>` block in `index.html`. Each row
  needs a video, a matching poster, a number, a title and a collaborator line.
  Keep `row--last` on the final row; it draws the closing rule.
- **Bio, history, certification** — the `.intro` section of `index.html`.
- **Colours and spacing** — the `:root` block at the top of `css/styles.css`.

The work list is static HTML rather than rendered from JSON, so it is
crawlable and works with JavaScript disabled.

## Colour

Light aurora: a near-white ground with blue and orange accents matched in
oklch (L 0.62 / C 0.16) so neither dominates.

Every text colour clears WCAG AA on `--paper` (#fafdff). Two pairs exist
because contrast depends on size — `--blue` and `--orange` are for large
display type and non-text marks; `--blue-deep` (7.07:1) and `--orange-deep`
(5.73:1) are for anything small. Check any new colour before using it:
light greys look correct on a white ground but fail badly.

## Video previews

Rows carry `preload="none"` with a poster image, so a visit costs ~350 KB of
posters rather than 11 MB of video. Hovering a row calls `play()`, which
fetches the clip on demand; leaving rewinds to 2.5s, the frame the posters
were cut from. Touch devices never load video at all — they keep the poster.

Do not set `preload` in the hover handler: that starts a second load which
aborts the in-flight `play()`.

